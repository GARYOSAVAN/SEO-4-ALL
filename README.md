# GARYOSAVAN BerkAI Prompt Library

A practical, versioned collection of reusable AI prompts for image generation, technical visualization, 3D-printable workflows, portfolio/product SEO, and AI video production.

## About

**GARYOSAVAN** develops structured AI prompt systems designed to turn real-world references, technical data, and creative requirements into repeatable production workflows.

The goal of this repository is simple:

> **Reusable prompts. Clear inputs. Controlled outputs. Repeatable results.**

## Categories

- `image-generation/` — engineering visuals, technical illustrations, mecha and product workflows
- `seo/` — marketplace and portfolio SEO prompt systems
- `video/` — short-form and assembly-video generation systems
- `templates/` — reusable prompt-building templates

## Supported AI Tools

Prompts are written to be adaptable to modern multimodal AI systems, including Gemini/Imagen and ChatGPT image generation. Tool-specific behavior may vary.

## How to Use

1. Open the relevant `.md` file.
2. Read the **INPUT** section.
3. Replace only the requested placeholders.
4. Paste the complete prompt into your AI tool.
5. Keep the same reference image(s) and requirements when iterating.
6. Record successful changes in a new version rather than silently overwriting the original.

## Prompt Design Principles

- Reference-first workflow
- Explicit subject and variant locking
- Geometry and proportion preservation
- No unauthorized redesign
- Clear positive and negative constraints
- Deterministic output requirements where possible
- Version-controlled iteration
- Separation of source data from presentation style

## Versioning

Prompt versions use `MAJOR.MINOR` format.

- **MAJOR** — workflow or behavior change
- **MINOR** — refinement, clarification, or quality improvement
