# Universal Marketplace SEO Prompt

**Version:** 1.0

Analyze the supplied product/artwork before writing anything.

Generate SEO copy based only on the actual subject and supplied information.

Prioritize:
1. Exact product identity
2. Primary buyer search intent
3. Specific model/type
4. Product format
5. Practical use case
6. Relevant niche terminology

Avoid:
- keyword stuffing
- invented specifications
- irrelevant trending keywords
- competitor names unless explicitly relevant
- generic filler

Output only the fields requested by the destination platform.
